# WebRTC Echo Project (FastAPI + aiortc)

A production-ready WebRTC signaling and audio echo backend.

## Local Setup
1. `python3 -m venv .venv`
2. `source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. `python main.py`
5. Visit `http://localhost:8000`

## Production Deployment
See `walkthrough.md` for the Kamatera Cloud Console guide.
Use `./run_prod.sh` to start the server in a production environment.
